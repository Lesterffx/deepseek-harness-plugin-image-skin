# Harness Image Skin

这是一份由 Harness Skin Studio 根据单张图片生成的 DeepSeek Harness Web 皮肤插件。

## 安装

```bash
dsh plugin --profile web add ./harness-image-skin-1.0.0.tgz
dsh web
```

## 卸载

```bash
dsh plugin --profile web remove harness-image-skin
```
